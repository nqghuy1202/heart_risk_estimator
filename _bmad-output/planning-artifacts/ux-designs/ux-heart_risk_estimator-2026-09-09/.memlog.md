- (decision) Scope is a visual/UX refresh only: no new screens, no new user flows, no backend changes. Existing component structure (TopBar, PredictionForm, Field, Verdict, Awaiting) stays.
- (decision) Stakes: consumer portfolio piece for AI/Python Engineer job applications, health-adjacent subject matter but explicitly not a medical device -- copy already disclaims this ('Not a medical device', 'Trained on 1,025 public records for a coursework project').
- (decision) Must preserve: zero network dependency (no external fonts/CDN/web fonts), keyboard navigation, aria-describedby wiring for help/errors, and no color-only distinction between the two verdict states (elevated risk vs low risk).
- (assumption) Primary audience for the redesign is hiring managers/recruiters evaluating the portfolio project, not real patients -- so the design should read as clinically credible rather than being clinically validated.
- (event) Rendered 3 design directions as an Artifact for user review: A) Clinical Trust (soft teal, rounded, reassuring), B) Cardiology Precision (dark instrument panel, cyan/crimson, ECG motif), C) Diagnostic Report (serif+mono lab-report register, closest to current editorial style).
